# Markatze-lengoaiak

Atal honetan web interfazearen garapena, egitura eta estiloen aplikazioa deskribatzen dira.

## 1. Web Orriaren Egitura (HTML5)
- Egitura semantikoa: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`.
- Formularioko eremuak eta sarrerako datuen baliozkotze automatikoa (`required`, motak, patroiak).
- Irisgarritasun-arauak (WAI-ARIA, `alt` atributuak, etiketa egokiak).

## 2. Diseinua eta Estiloak (CSS3)
- Selektoreak, klaseak eta identifikadoreak.
- Diseinu moldagarria (Responsive Web Design) eta **Media Queries**.
- Antolaketa-tresna modernoak: **Flexbox** eta **CSS Grid**.

## 3. Datuen Trukatzea eta Formatuak
- **JSON / XML**: Datuak biltegiratzeko eta aplikazioen artean trukatzeko formatuak.
- Datuen baliozkotzea eta eredu-egiturak.
