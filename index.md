# Ongi etorri Erronka 1-eko Dokumentaziora

Atari honetan Erronka 1-en garatutako proiektuaren atal eta ikasgai desberdinen inguruko dokumentazio teknikoa aurkituko duzu.

Ikasgai bakoitzeko atalak honako hauek dira:

- [**Datu-baseak**](datubase.html) (`datubase.md`): Datu-eredua, taulak, kontsultak eta erabilitako erlazio-diseinua.
- [**Digitalizazioa (DIGIT)**](digit.html) (`digit.md`): Eraldaketa digitala, prozesuen optimizazioa eta tresna digitalak.
- [**Sareak**](sareak.html) (`sareak.md`): Sare-azpiegitura, IP helbideraketa, protokoloak eta arkitektura.
- [**Markatze-lengoaiak**](markatze.html) (`markatze.md`): Web garapena, HTML5, CSS3, baliozkotzeak eta diseinu sentikorra.
- [**Sistema Eragileak**](sistemaeragileak.html) (`sistemaeragileak.md`): Zerbitzarien konfigurazioa, baimenak, erabiltzaileak eta ingurunearen kudeaketa.

Aukeratu goiko menuko atal bat edo zerrendako estekaren bat informazio zehatzagoa ikusteko.
