# Sareak

Atal honetan proiektuaren sare-azpiegitura, konexioak eta komunikazio-protokoloak xehatzen dira.

## 1. Sare-Topologia eta Diseinua
- Sare lokalaren (LAN) diseinua eta gailuen banaketa.
- Bideratzaileak (router), kommutadoreak (switch) eta kableatu egituratua.

## 2. IP Helbideraketa
- **IPv4 helbideraketa plana**: Sare-maskarak, CIDR notazioa eta azpisareen (subnetting) zatiketa.
- **DHCP konfigurazioa**: IP helbideen esleipen automatikoa gailuentzat.
- DNS zerbitzariaren parametrizazioa eta izen-ebazpena.

## 3. Protokoloak eta Zerbitzuak
- **TCP/IP pila**: Garraio- eta sare-geruzaren funtzionamendua.
- **Aplikazio-protokoloak**: HTTP/HTTPS, SSH, FTP/SFTP, DNS.

## 4. Segurtasuna Sarean
- Suhesi (firewall) konfigurazioa eta ataken irekiera/itxiera.
- Sareen isolamendua (VLAN) eta sarbide kontrolak.
